# 小猫捕鱼大作战

一个原创 HTML5 Canvas 休闲小游戏。玩家控制小猫的捕食范围，在池塘里吞掉更小的鱼虾蟹，逐步变大，并在 60 秒内挑战三星评价。

## 游戏玩法

- 电脑端：移动鼠标、方向键或 WASD 控制小猫移动。
- 手机端：用手指触摸并拖动控制小猫移动。
- 调试信息：按 `D` 可显示/隐藏玩家半径、当前阶段、分数和对象数量。
- 只能吞掉明显小于当前小猫的物体。
- 池塘地图大于屏幕，画面会跟随小猫移动。
- 吞掉物体后会获得分数，小猫捕食范围会略微变大。
- 物体外圈高亮表示可以吃；红色虚线圈是危险边界，小猫白圈碰到它会失败。
- 红圈危险目标会在靠近小猫时缓慢追踪，制造压迫感。
- 碰到当前不能吃的目标会失败。
- 60 秒内达到 850 分获得一星，1200 分获得二星，1400 分获得三星；时间结束仍未达到一星则失败。
- 1200 分后小猫会成长到可以吞鳄鱼的体型，鳄鱼每条 100 分，并会继续补充。

## 如何运行

直接双击 `index.html`，用浏览器打开即可运行。

不需要安装 Node.js，不需要安装依赖，也不需要联网。

## 文件结构

```text
index.html   页面结构和开始/结束界面
style.css    页面布局、按钮、弹窗和整体视觉样式
game.js      Canvas 绘制、游戏状态、输入、碰撞和计分逻辑
README.md    项目说明
```

## 主要数值

- 初始玩家半径：22
- 地图初始物体数量：78 个随机物体，额外 5 条大鱼
- 游戏时间：60 秒
- 星级目标：850 / 1200 / 1400 分
- 吞噬条件：目标半径小于玩家半径的 0.74 倍
- 危险规则：碰到当前不能吞噬的目标会失败
- 成长规则：每次吞噬后，玩家半径增加目标半径的 0.065
